# Logo sources

- `ksm-iot.png` and `sudut-pandang.png`: original files supplied by the portfolio owner. Copied without redrawing, recoloring, or changing the source files.
- `fusion.png`: largest original frame from the installed Autodesk Fusion application icon, exported losslessly from ICO to PNG. Product: https://www.autodesk.com/products/fusion-360/overview
- `anycubic-slicer.png`: original AnycubicSlicer.png distributed with the installed Anycubic Slicer Next application. Product: https://www.anycubic.com/
- `arduino-ide.png`: original application icon from the official Arduino IDE repository: https://github.com/arduino/arduino-ide/blob/main/electron-app/resources/icons/512x512.png
- `autocad.svg`: original product-badge SVG displayed in the product bundle on Autodesk's AutoCAD overview page: https://www.autodesk.com/products/autocad/overview

The artwork identifies the tools and organizations listed in the portfolio. All brand names and logos belong to their respective owners.
